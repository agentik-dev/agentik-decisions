The owner typed this command, so the owner's word is present. Follow the page of this
plugin's `instruct` skill (`skills/instruct/SKILL.md`) with these words: $ARGUMENTS

- `where`: print its table "Where each thing is set", each value read by the row's
  "shown by" command. Change nothing.
- `adopt <file>`: review a hand edit of the file after the fact: the eight tests on each
  added line, the loaded bytes beside the ceiling from `agentik decisions render
  --check`, and the offer to move a hand-added rule into the ledger.
- Anything else is the change, in the owner's words: the flow's eight steps, and at step
  6 ask at once, one question with the recommended answer first.

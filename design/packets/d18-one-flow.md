## 2. Rulings

Standing rules. You are the builder: do every act yourself, in the foreground, and commit it before the next starts. Paths are repo-relative. `P` is the directory that holds the main checkout. `X` is the cross-repo ledger: the path on the `Generated from` line of the decisions block in your user-level CLAUDE.md. Tests run with `PYTHONPATH=src`: the virtualenv may import the main checkout's package. The charter is the first free `history/sittings/<YYYY-MM-DD>-<n>-d18.md`, opened at act 1: `# Sitting <date>-<n>: claude-code-decisions, d18-one-flow`, doclint's five rows (goal, budget, pin, window, agents), `## Done-ness`, `## Handover`, `## Next act`; closed before the last commit, under 4,096 bytes, no home path. Each act's first test is red on `main`; `make check` is 0 at each commit. Choices inside the design go in the charter; a fork the design cannot settle goes in the Handover, and the act lands without it. Write commit messages with the Write tool and commit with `git commit -F <file>`.
